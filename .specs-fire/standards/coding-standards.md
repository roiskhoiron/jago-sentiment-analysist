# Coding Standards

## Overview

Use clean, modular, reproducible Python code for scraping, preprocessing, training, evaluation, and inference.

## Code Formatting

**Tool**: black
**Config**: pyproject.toml
**Enforcement**: Pre-commit or CI

### Key Settings

- **line-length**: 88
- **target-version**: py310

## Linting

**Tool**: ruff
**Base Config**: default + pyflakes/pycodestyle/import-sort
**Strictness**: medium

### Key Rules

- `F401`: error — prevent unused imports
- `F841`: error — prevent unused variables
- `E722`: error — avoid bare except
- `I001`: warning — enforce import sorting

## Naming Conventions

### Variables and Functions

| Element | Convention | Example |
| function | snake_case | `train_indobert_model` |
| variable | snake_case | `cleaned_reviews` |
| constant | UPPER_SNAKE_CASE | `RANDOM_SEED` |
| class | PascalCase | `SentimentDataset` |

### Files and Folders

- **python files**: snake_case (e.g., `preprocessing_pipeline.py`)
- **notebooks**: numeric prefix order (e.g., `01_scraping.ipynb`)
- **artifacts**: descriptive snake_case (e.g., `tfidf_vectorizer.pkl`)

## File Organization

### Project Structure

```
project/
  data/
  notebooks/
  src/
  models/
  artifacts/
```

### Conventions

- **Single responsibility**: Each module handles one pipeline stage
- **Config constants**: Centralize seeds and paths
- **No hidden state**: Pass artifacts explicitly between stages

## Import Order

```python
import os
import re

import numpy as np
import pandas as pd
from sklearn.feature_extraction.text import TfidfVectorizer
```

**Rules**:
- Standard library first
- Third-party second
- Local imports last

## Error Handling

### Pattern

**Approach**: Explicit exceptions with actionable messages

### Guidelines

- Validate required columns before training
- Fail fast on empty datasets
- Raise descriptive errors for missing model artifacts

### Example

```python
if "review_text" not in df.columns:
    raise ValueError("Missing required column: review_text")
```

## Logging

**Tool**: logging
**Format**: timestamp + level + message

### Log Levels

| Level | Usage |
|-------|-------|
| INFO | pipeline progress |
| WARNING | recoverable data quality issue |
| ERROR | fatal stage failure |

### Guidelines

**Always log**:
- dataset size before/after filtering
- train/test split and random seed
- evaluation metrics per experiment

**Never log**:
- secrets or credentials
- sensitive personal user metadata

## Comments and Documentation

### When to Comment

- Explain non-obvious preprocessing assumptions
- Document label mapping and class definitions
- Clarify experiment differences

### Documentation Format

**Functions**: Google-style docstrings
**Classes**: Class-level docstrings

## Code Patterns

### Preferred Patterns

#### Pipeline Functions

Composable functions for each stage with deterministic outputs.

```python
def preprocess_text_series(series: pd.Series) -> pd.Series:
    return series.fillna("").str.lower()
```

### Anti-Patterns to Avoid

- **Notebook-only hidden logic**: hard to reproduce in other environments
- **In-place unlabeled mutation**: reduces traceability
