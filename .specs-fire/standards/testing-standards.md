# Testing Standards

## Overview

Ensure deterministic, reproducible experiments and valid metric reporting for sentiment classification.

## Testing Framework

**Framework**: pytest
**Runner**: pytest

## Test Types

| Type | Tool | Location | When to Use |
| unit | pytest | `tests/unit/` | validate preprocessing, labeling, and utility functions |
| integration | pytest | `tests/integration/` | validate end-to-end pipeline stages |
| notebook smoke | nbclient/pytest | `tests/notebooks/` | ensure notebooks run sequentially |

## Coverage Requirements

**Target**: 80%
**Enforcement**: CI threshold

**Critical paths that MUST have coverage:**
- scraping output schema validation
- preprocessing transformations
- label mapping and class balance checks
- inference categorical output mapping

## Test Naming

**Pattern**: `test_<module>_<behavior>`

**Examples**:
- `test_preprocess_removes_urls` — verifies URL cleanup
- `test_inference_returns_valid_label` — verifies Positive/Neutral/Negative output

## Test Structure

```python
def test_behavior():
    # arrange
    # act
    # assert
```

## Mock Strategy

**Approach**: Mock network calls only where needed

**Guidelines**:
- Prefer real local sample data for preprocessing tests
- Mock scraping endpoints for stability in CI
- Do not mock evaluation metrics

## Test Data

**Strategy**: Versioned fixtures and small representative samples

**Guidelines**:
- Keep fixtures in Indonesian text
- Include all three sentiment classes
- Include noisy text examples (emoji, URL, slang)

## Running Tests

```bash
# Run all tests
pytest

# Run with coverage
pytest --cov=src --cov-report=term-missing

# Run specific test file
pytest tests/unit/test_preprocessing.py

# Run in watch mode
pytest -f
```
